# Cluck Life

Multiplayer cock fighting game inspired by **Duck Life** (raise & train) and **Grow a Chicken Fighter** (progression, fusion, pit fights).

## Features (prototype)
- Raise and feed your chicken
- Training actions that boost stats
- Level up and allocate points (MMO style)
- Fight AI opponents with virtual coin betting
- Simple auto-combat based on stats

## Roadmap
- Pixel art sprites
- Training minigames
- Egg hatching & fusion
- Real multiplayer + betting
- Rebirth system
- Special abilities

Open `index.html` in a browser to play the current prototype, or run `npm start` and visit http://127.0.0.1:8765.

```bash
npm test    # node tests for betting, rest, and combat rules
npm start   # static file server
```

No build step and no hosted deploy config (no Wrangler / Pages project). It is a static HTML + JS prototype.
