# Cluck Life

Multiplayer cock fighting game inspired by **Duck Life** (raise & train) and **Grow a Chicken Fighter** (progression, fusion, pit fights).

## Features (prototype)
- Raise and feed your chicken
- Training actions that boost stats
- Level up and allocate points (MMO style)
- Fight AI opponents with virtual coin betting
- Simple auto-combat based on stats

## Roadmap
- Pixel art sprites
- Training minigames
- Egg hatching & fusion
- Real multiplayer + betting
- Rebirth system
- Special abilities

Open `index.html` in a browser to play the current prototype.
